## 🤝 Community & Contribution

We believe in the power of **Open Source**. This repository is built by students, for students.

**Want to contribute?** Use this checklist:

1. Check the [**Contribution Guidelines**](CONTRIBUTING.md) 📜
2. Look for issues labeled `good first issue` or `help wanted`.
3. Have a new idea? Open a [**Resource Suggestion**](.github/ISSUE_TEMPLATE/resource_suggestion.yml).
4. Found a typo? Open a [**Bug Report**](.github/ISSUE_TEMPLATE/bug_report.yml).
