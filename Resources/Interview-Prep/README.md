# Interview Prep

Structured resources to help you systematically prepare for technical job interviews. This section covers data structures and algorithms, system design, behavioral questions, complexity analysis, and curated practice problems.

## Available Resources

| Resource | Description |
|----------|-------------|
| [DSA Study Guide](./DSA-Study-Guide.md) | Comprehensive guide to data structures and algorithms — arrays, linked lists, trees, graphs, hash maps, sorting, and searching. |
| [System Design Guide](./System-Design-Guide.md) | System design interview guide covering scalability, caching, databases, load balancing, and API design patterns. |
| [Behavioral Interview Guide](./Behavioral-Interview-Guide.md) | Behavioral interview preparation using the STAR method, with common question categories and structured answer frameworks. |
| [Big-O Cheatsheet](./Big-O-Cheatsheet.md) | Quick-reference for time and space complexity of common operations, data structures, and algorithms in Big-O notation. |
| [Practice Problems](./Practice-Problems.md) | Curated list of 30+ LeetCode-style practice problems organized by topic and difficulty, with links to problem sources. |

## How to Use

- Start with the **DSA Study Guide** if you need to build or refresh your fundamentals.
- Use the **Big-O Cheatsheet** alongside your algorithm study as a quick complexity reference.
- Work through **Practice Problems** by topic once you've reviewed the relevant DSA concepts.
- Study the **System Design Guide** for mid-to-senior level roles that include architecture rounds.
- Review the **Behavioral Interview Guide** before any interview — behavioral rounds are universal.
