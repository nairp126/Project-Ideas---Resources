## Contents

### [Sorting Algorithms](./Sorting-Algorithms.md)

Covers four essential sorting algorithms with full complexity analysis and implementations:

- **Bubble Sort** — Simple comparison-based sort; great for learning fundamentals
- **Merge Sort** — Divide-and-conquer sort; stable and efficient for large datasets
- **Quick Sort** — In-place divide-and-conquer; fast average-case performance
- **Heap Sort** — Comparison-based sort using a binary heap data structure

### [Searching Algorithms](./Searching-Algorithms.md)

Covers three core searching techniques used in interviews and real-world systems:

- **Binary Search** — Efficient search on sorted arrays using divide-and-conquer
- **Breadth-First Search (BFS)** — Level-by-level graph/tree traversal
- **Depth-First Search (DFS)** — Deep-path graph/tree traversal using a stack

### [Dynamic Programming](./Dynamic-Programming.md)

Covers three classic dynamic programming problems that appear frequently in interviews:

- **Fibonacci Sequence** — Memoization and tabulation approaches
- **0/1 Knapsack** — Optimization problem with weight and value constraints
- **Longest Common Subsequence (LCS)** — String comparison and alignment

### [Data Structures Reference](./Data-Structures-Reference.md)

Covers seven fundamental data structures with explanations, use cases, and Python code examples:

- **Arrays** — Contiguous memory, O(1) index access
- **Linked Lists** — Dynamic node-based sequences
- **Stacks** — LIFO (Last In, First Out) structures
- **Queues** — FIFO (First In, First Out) structures
- **Trees** — Hierarchical node structures (binary trees, BSTs)
- **Graphs** — Networks of nodes and edges
- **Hash Maps** — Key-value stores with O(1) average lookup
