# Resources

A collection of reference materials, guides, and tools to support your learning and development workflow. Browse by category to find what you need.

## Sections

| Directory | Description |
|-----------|-------------|
| [Cheatsheets/](./Cheatsheets/README.md) | Quick-reference guides for Git, Linux/Bash, Docker, SQL, Python, JavaScript, React, TypeScript, Regex, and Markdown |
| [Free-Tools/](./Free-Tools/README.md) | Curated list of free IDEs, hosting platforms, databases, and design tools for students |
| [Guides/](./Guides/README.md) | Practical guides covering GitHub profile optimization, open source contribution, and developer workflow |
| [Interview-Prep/](./Interview-Prep/README.md) | DSA study guide, system design guide, behavioral interview guide, Big-O cheatsheet, and practice problems |
| [Snippets/](./Snippets/README.md) | Reusable code snippets for Python, JavaScript, and Go covering auth, APIs, databases, sorting, and strings |
| [Algorithms/](./Algorithms/README.md) | Sorting, searching, dynamic programming, and data structures reference with pseudocode and Big-O analysis |

## How to Use

- Use **Cheatsheets** for quick syntax and command lookups while you are coding.
- Use **Interview-Prep** to systematically prepare for technical job interviews.
- Use **Snippets** to copy common patterns directly into your projects.
- Use **Algorithms** to study computer science fundamentals alongside practical projects.
- Use **Guides** for step-by-step walkthroughs of professional developer practices.
- Use **Free-Tools** to find no-cost tools for building and deploying your projects.
