# Guides

Practical guides covering open source contribution, developer productivity, and GitHub profile optimization. Each guide provides step-by-step instructions, real-world examples, and actionable advice for developers at all levels.

## Available Guides

| Guide | Description |
|-------|-------------|
| [GitHub Profile Guide](./GitHub-Profile-Guide.md) | How to structure and optimize your GitHub profile to stand out to recruiters and collaborators. |
| [Open Source Guide](./Open-Source-Guide.md) | How to find beginner-friendly repositories, understand codebases, write good pull requests, and respond to code review feedback. |
| [Developer Workflow Guide](./Developer-Workflow-Guide.md) | Terminal customization, dotfiles management, Git aliases, local environment setup, and debugging techniques. |

## How to Use

- Read the **GitHub Profile Guide** before applying for jobs or internships to make sure your profile is recruiter-ready.
- Follow the **Open Source Guide** when you are ready to make your first open source contribution.
- Use the **Developer Workflow Guide** to level up your day-to-day productivity with better tooling and habits.
