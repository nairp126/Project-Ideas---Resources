# Cheatsheets

Quick-reference guides for the tools, languages, and technologies developers use every day. Each cheatsheet is organized into clearly labeled sections with code examples you can copy directly into your workflow.

## Available Cheatsheets

| Cheatsheet | Description |
|------------|-------------|
| [Git](./Git-Cheatsheet.md) | Essential Git commands for version control — setup, branching, merging, and syncing with remotes. |
| [Linux/Bash](./Linux-Bash-Cheatsheet.md) | Core Linux commands and Bash scripting — navigation, file operations, permissions, processes, and text processing. |
| [Docker](./Docker-Cheatsheet.md) | Docker CLI commands, Dockerfile syntax, Docker Compose, and container debugging. |
| [SQL](./SQL-Cheatsheet.md) | SQL queries, joins, aggregation, window functions, and schema definition for relational databases. |
| [Python](./Python-Cheatsheet.md) | Python syntax, data structures, comprehensions, file I/O, OOP, and standard library essentials. |
| [JavaScript](./JavaScript-Cheatsheet.md) | Modern JavaScript (ES6+) — variables, functions, arrays, objects, async/await, and DOM manipulation. |
| [React](./React-Cheatsheet.md) | React hooks, component patterns, context API, forms, and performance optimization (React 18+). |
| [TypeScript](./TypeScript-Cheatsheet.md) | TypeScript types, interfaces, generics, utility types, classes, and tsconfig options. |
| [Regex](./Regex-Cheatsheet.md) | Regular expression syntax, character classes, quantifiers, groups, lookaheads, and common patterns. |
| [Markdown](./Markdown-Cheatsheet.md) | Markdown and GitHub Flavored Markdown syntax — headings, tables, code blocks, links, and callouts. |

## How to Use

- Use `Ctrl+F` / `Cmd+F` to search within any cheatsheet for a specific command or keyword.
- Each cheatsheet has a **Table of Contents** at the top — click any link to jump directly to that section.
- All code examples use fenced code blocks with language identifiers for syntax highlighting.
