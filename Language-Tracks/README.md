# Language-Specific Project Tracks

This directory contains project ideas organized by programming language. Each track includes beginner through intermediate projects tailored to the idioms and ecosystem of that language.

## Available Tracks

| Language | File | Level Range |
|---|---|---|
| Python | [Python.md](./Python.md) | Beginner → Intermediate |
| JavaScript | [JavaScript.md](./JavaScript.md) | Beginner → Intermediate |
| Java | [Java.md](./Java.md) | Beginner → Intermediate |
| C++ | [C++.md](./C++.md) | Beginner → Intermediate |
| Go | [Go.md](./Go.md) | Beginner → Intermediate |

## How to Use These Tracks

1. Pick the language you are currently learning or want to practice.
2. Start with the **Beginner** projects to get comfortable with the language's syntax and standard library.
3. Move to **Intermediate** projects once you are confident with the basics.
4. Each project entry specifies the required language version or runtime so you can set up your environment correctly.
