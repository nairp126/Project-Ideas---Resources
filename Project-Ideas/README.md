# Project Ideas

A curated catalog of project ideas organized by difficulty level. Whether you are just starting out or ready for a production-scale challenge, there is a project here for you.

## Difficulty Levels

| Directory | Description |
|-----------|-------------|
| [Beginner/](./Beginner/README.md) | 15+ beginner project ideas with problem descriptions, tech stacks, and bonus challenges |
| [Intermediate/](./Intermediate/README.md) | 15+ intermediate project ideas with problem statements, database schemas, and API endpoints |
| [Advanced/](./Advanced/README.md) | 10+ advanced project ideas with microservices architecture and system design challenges |

## How to Choose a Project

- **Beginner** — you are learning your first language or framework and want to build something small and complete.
- **Intermediate** — you are comfortable with the basics and want to build something with a real database, API, and multiple features.
- **Advanced** — you are ready to tackle distributed systems, microservices, cloud infrastructure, and system design.
