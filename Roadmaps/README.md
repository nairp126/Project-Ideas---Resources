## How to Use a Roadmap

1. **Pick your target role** — choose the roadmap that matches the career path you are pursuing.
2. **Follow the phases in order** — each month builds on the previous one. Don't skip ahead.
3. **Build the projects** — each phase includes a "Build This" section with hands-on projects.
4. **Check the salary section** — use the salary and job market data to set realistic expectations.
5. **Avoid the common mistakes** — each roadmap lists pitfalls that learners frequently encounter.
