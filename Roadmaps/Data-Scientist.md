# 📊 Data Scientist Roadmap (18 Months)

This comprehensive roadmap guides you from a beginner to a job-ready Data Scientist over 18 months. It covers Mathematics, Programming, Machine Learning, Deep Learning, and MLOps.

---

## Quarter 1 (Month 1-3): Foundations

### 🎯 Learning Objectives

Master the tools of the trade: Python, Mathematics, and Data Analysis.

### 📊 Math & Statistics

* **Linear Algebra:** Vectors, Matrices, Operations, Eigenvalues.
* **Calculus:** Derivatives, Gradients, Partial Derivatives (conceptually).
* **Statistics:** Mean, Median, Mode, Variance, Standard Deviation, Probability Distributions (Normal, Binomial), Hypothesis Testing (p-values, t-tests).

### 🐍 Programming & Tools

* **Python:** Syntax, Control Flow, Functions.
* **NumPy:** Vectorized operations, Broadcasting.
* **Pandas:** DataFrames, Filtering, GroupBy, Merging.
* **Visualization:** Matplotlib (basics), Seaborn (statistical plots).
* **IDE:** Jupyter Notebooks / JupyterLab.

### 🧠 Core ML Concepts

* **Exploratory Data Analysis (EDA):** Understanding data distribution, missing values, outliers.
* **Data Cleaning:** Imputation, One-Hot Encoding, Normalization.

### 🗂️ Practice Datasets

* Titanic (Kaggle)
* Iris Species
* Wine Quality

### 💼 Portfolio Project

* **Title:** Comprehensive EDA on Real-World Data
* **Description:** Choose a dataset (e.g., Global Happiness Index), clean it, visualize trends, and derive actionable insights.
* **Skills Demonstrated:** Data Wrangling, Visualization, Storytelling.
* **Dataset Source:** Kaggle / UCI Machine Learning Repository.

### 📚 Learning Resources

* **Mathematics:** [Khan Academy - Linear Algebra](https://www.khanacademy.org/math/linear-algebra)
* **Programming:** [Pandas Documentation](https://pandas.pydata.org/docs/)
* **Practical:** [Kaggle Learn](https://www.kaggle.com/learn)

### 🏆 Kaggle Competitions (Recommended)

* Titanic: Machine Learning from Disaster (EDA focus)

### ✅ Success Metrics

You can load a raw CSV, clean the messy data, and create 5-10 meaningful visualizations that explain "what is happening" in the data.

---

## Quarter 2 (Month 4-6): Machine Learning Fundamentals

### 🎯 Learning Objectives

Understand and implement core Supervised Learning algorithms.

### 📊 Math & Statistics

* **Optimization:** Gradient Descent, Cost Functions.
* **Metrics:** R-squared, MSE, Accuracy, Precision, Recall, F1-Score, ROC/AUC.

### 🐍 Programming & Tools

* **Scikit-Learn:** The industry standard for classical ML.
* **Statsmodels:** For more statistical approaches.

### 🧠 Core ML Concepts

* **Supervised Learning:**
  * **Regression:** Linear, Polynomial, Ridge, Lasso.
  * **Classification:** Logistic Regression, Decision Trees, SVM, KNN.
* **Model Evaluation:** Train-Test Split, Cross-Validation (K-Fold).
* **Bias-Variance Tradeoff:** Overfitting vs. Underfitting.
* **Regularization:** L1 vs L2 penalties.

### 🗂️ Practice Datasets

* California Housing Prices
* Telco Customer Churn
* Breast Cancer Wisconsin

### 💼 Portfolio Project

* **Title:** Predictive Modeling for Business
* **Description:** Build a model to predict house prices or customer churn. Focus on feature selection and interpreting coefficients.
* **Skills Demonstrated:** Regression/Classification, Model Eval, Feature Engineering.
* **Dataset Source:** Kaggle.

### 📚 Learning Resources

* **ML Theory:** [Andrew Ng's Machine Learning Specialization (Coursera)](https://www.coursera.org/specializations/machine-learning-introduction)
* **Practical:** [Scikit-Learn User Guide](https://scikit-learn.org/stable/user_guide.html)

### 🏆 Kaggle Competitions (Recommended)

* House Prices: Advanced Regression Techniques

### ✅ Success Metrics

You can take a dataset, split it, train a model, evaluate it using appropriate metrics, and explain *why* it predicts what it predicts.

---

## Quarter 3 (Month 7-9): Advanced ML & Ensemble Methods

### 🎯 Learning Objectives

Master powerful algorithms and work with unlabeled data.

### 📊 Math & Statistics

* **Information Theory:** Entropy, Gini Impurity (for trees).
* **Dimensionality:** Eigenvectors (PCA).

### 🐍 Programming & Tools

* **XGBoost / LightGBM:** Gradient Boosting libraries.
* **SHAP / LIME:** Model explainability.

### 🧠 Core ML Concepts

* **Ensemble Methods:** Random Forest, Gradient Boosting, Stacking.
* **Unsupervised Learning:**
  * **Clustering:** K-Means, Hierarchical, DBSCAN.
  * **Dimensionality Reduction:** PCA, t-SNE, UMAP.
* **Time Series:** ARIMA, Prophet basics.
* **Hyperparameter Tuning:** GridSearch, RandomSearch.

### 🗂️ Practice Datasets

* Mall Customer Segmentation
* Daily Sales Forecasting

### 💼 Portfolio Project

* **Title:** End-to-End ML Pipeline
* **Description:** Build a pipeline that takes raw data, processes it, trains an XGBoost model with tuned hyperparameters, and saves the model.
* **Skills Demonstrated:** Pipeline construction, Hyperparameter optimization, Ensemble learning.
* **Dataset Source:** UCI / Kaggle.

### 📚 Learning Resources

* **Practical:** [XGBoost Documentation](https://xgboost.readthedocs.io/)
* **Theory:** [StatQuest with Josh Starmer (YouTube)](https://www.youtube.com/c/joshstarmer)

### 🏆 Kaggle Competitions (Recommended)

* Store Sales - Time Series Forecasting

### ✅ Success Metrics

You understand why Random Forest is often better than a single Decision Tree and can group similar data points using Clustering.

---

## Quarter 4 (Month 10-12): Deep Learning Foundations

### 🎯 Learning Objectives

Enter the world of Neural Networks and Computer Vision.

### 📊 Math & Statistics

* **Linear Algebra:** Tensors, Matrix Multiplication.
* **Calculus:** Chain Rule (Backpropagation).

### 🐍 Programming & Tools

* **TensorFlow / PyTorch:** (Pick one framework, PyTorch is trending for research).
* **Keras:** High-level API.

### 🧠 Core ML Concepts

* **Neural Networks:** Perceptrons, Activation Functions (ReLU, Sigmoid), Backpropagation.
* **Computer Vision:** Convolutional Neural Networks (CNNs), Pooling, Padding.
* **Transfer Learning:** Using VGG16, ResNet.
* **Basic NLP:** Tokenization, Word Embeddings (Word2Vec).

### 🗂️ Practice Datasets

* MNIST / Fashion MNIST
* CIFAR-10
* IMDB Movie Reviews

### 💼 Portfolio Project

* **Title:** Image Classifier App
* **Description:** Train a CNN to classify images (e.g., cats vs. dogs) or X-ray disease detection.
* **Skills Demonstrated:** Deep Learning, CNNs, Computer Vision.
* **Dataset Source:** Kaggle.

### 📚 Learning Resources

* **Course:** [Deep Learning Specialization (Andrew Ng)](https://www.deeplearning.ai/courses/deep-learning-specialization/)
* **Practical:** [PyTorch Blitz](https://pytorch.org/tutorials/beginner/deep_learning_60min_blitz.html)

### 🏆 Kaggle Competitions (Recommended)

* Digit Recognizer (MNIST)

### ✅ Success Metrics

You can build a simple Neural Network from scratch and a CNN using a framework to classify images with high accuracy.

### 💼 Portfolio Project

* **Title:** Intelligent Chatbot / Summarizer
* **Description:** Fine-tune a BERT/GPT model for a specific task (e.g., legal document summarization).
* **Skills Demonstrated:** NLP, Transformers, Transfer Learning.
* **Dataset Source:** Hugging Face Datasets.

### 📚 Learning Resources

* **Course:** [Hugging Face Course](https://huggingface.co/course/chapter1/1)
* **Book:** Deep Learning with Python (Francois Chollet).

### 🏆 Kaggle Competitions (Recommended)

* Natural Language Processing with Disaster Tweets

You understand the Attention mechanism and can fine-tune a pre-trained Transformer model for a custom task.

## Quarter 6 (Month 16-18): MLOps & Production

### 🎯 Learning Objectives

Move models from notebooks to the real world.

### 🐍 Programming & Tools

* **Deployment:** Flask / FastAPI.
* **Containerization:** Docker.
* **Tracking:** MLflow, DVC.
* **Cloud:** AWS SageMaker or Google Cloud AI.
* **Big Data:** SQL, Spark (Basic PySpark).

### 🧠 Core ML Concepts

* **Model Serving:** Real-time vs. Batch inference.
* **Monitoring:** Data Drift, Concept Drift.
* **A/B Testing:** Comparing model versions.

### 💼 Portfolio Project

* **Title:** Production ML System
* **Description:** Deploy a trained model as a REST API using FastAPI + Docker, deployed on a cloud provider with basic monitoring.
* **Skills Demonstrated:** MLOps, API Development, Deployment.

### 📚 Learning Resources

* **Book:** Designing Machine Learning Systems (Chip Huyen).
* **Course:** [Full Stack Deep Learning](https://fullstackdeeplearning.com/)

### ✅ Success Metrics

You have a model running in the cloud that can accept requests and return predictions.

## 🚀 Career & Portfolio Strategy

### 🐙 GitHub Portfolio

* **Readme matters:** Don't just dump code. Explain the problem, your approach, and results.
* **Clean Code:** Use functions, comments, and docstrings.

### ✍️ Personal Brand

* **Blog:** Write about what you learn. "Explaining a concept enforces understanding."
* **Website:** A simple static site linking to your best 3-5 projects.

### 🤝 Networking

* **Discord/Slack:** Join Python and Data Science communities.
* **LinkedIn:** Share your projects and learnings.

* **Case Studies:** "How would you design a recommendation system for Spotify?"

## 💰 Salary & Job Market

* **Median Salary (US):** $100,000–$145,000/year (Junior to Mid-level)
* **Senior Data Scientist / Staff:** $145,000–$220,000+
* **Top Hiring Companies:** Google, Meta, Amazon, Netflix, Airbnb, Spotify, and financial institutions (JPMorgan, Goldman Sachs)
* **In-Demand Skills:** Python, SQL, machine learning (scikit-learn, XGBoost), deep learning (PyTorch), statistics, data visualization, MLOps, communication skills
* **Job Market Note:** Data Science has matured significantly. Employers now expect production-ready skills (MLOps, SQL, software engineering practices) in addition to modeling ability. Pure "notebook scientists" are less competitive than those who can deploy and monitor models.

## ⚠️ Common Mistakes

1. **Focusing on models instead of data quality** — In practice, 80% of a data scientist's time is spent on data cleaning, feature engineering, and understanding the business problem. Developers who jump straight to complex models on messy data produce unreliable results. Master EDA and data wrangling first.
2. **Ignoring SQL** — SQL is the most-used skill in data science interviews and day-to-day work. Many candidates with strong Python skills fail interviews because they can't write a window function or optimize a slow query. Treat SQL as a first-class skill.
3. **Not communicating results to non-technical stakeholders** — A model that can't be explained to a business stakeholder won't be adopted. Data scientists who can translate technical findings into business impact are far more valuable than those who optimize metrics in isolation.
