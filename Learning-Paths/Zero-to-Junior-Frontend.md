# Zero to Junior Frontend Developer

## Overview

**Who this is for:** Complete beginners with little or no programming experience who want to land their first frontend or UI engineering role.

**Estimated total time:** 6–9 months (assuming 10–15 hours per week)

**Roadmap:** [Frontend Developer Roadmap](../Roadmaps/Frontend-Developer.md)

This path takes you from zero programming knowledge to a portfolio strong enough to apply for junior frontend roles. You'll learn HTML, CSS, and JavaScript fundamentals, then move into React and modern tooling, finishing with a capstone project that demonstrates real-world skills.

---

## Phase 1: Web Fundamentals (~6 weeks)

**Goal:** Understand how the web works and build static pages with HTML and CSS.

**Roadmap:** [Frontend Developer Roadmap — Phase 1](../Roadmaps/Frontend-Developer.md)

**What to learn:**
- HTML5 semantics (headings, lists, forms, tables, semantic elements)
- CSS fundamentals (box model, flexbox, grid, responsive design, media queries)
- How browsers render pages (DOM, CSSOM, critical rendering path)
- Basic Git and GitHub (commits, branches, pull requests)

**Projects to Build:**

1. [Personal Portfolio Page](../Project-Ideas/Beginner/README.md) — Build a static HTML/CSS portfolio with your name, a short bio, and links to your GitHub. Focus on clean layout and responsive design.
2. [Markdown Note-Taking CLI](../Project-Ideas/Beginner/README.md) — Practice file structure and content organization; adapt the concept to a static HTML notes page.

**Resources:**
- [Markdown Cheatsheet](../Resources/Cheatsheets/Markdown-Cheatsheet.md) — for writing README files and documentation
- [Git Cheatsheet](../Resources/Cheatsheets/Git-Cheatsheet.md) — essential Git commands for version control
- [Linux/Bash Cheatsheet](../Resources/Cheatsheets/Linux-Bash-Cheatsheet.md) — terminal basics you'll use every day
- [Developer Workflow Guide](../Resources/Guides/Developer-Workflow-Guide.md) — set up your editor, terminal, and Git aliases

**Milestone:** You can build a multi-page static website from scratch and push it to GitHub Pages.

---

## Phase 2: JavaScript Fundamentals (~6 weeks)

**Goal:** Write interactive JavaScript and understand core language concepts.

**Roadmap:** [Frontend Developer Roadmap](../Roadmaps/Frontend-Developer.md)

**What to learn:**
- Variables, data types, operators, control flow
- Functions, scope, closures, arrow functions
- Arrays and objects (map, filter, reduce)
- DOM manipulation and event handling
- Fetch API and working with JSON
- ES6+ syntax (destructuring, spread, template literals, modules)

**Projects to Build:**

3. [Number Guessing Game](../Project-Ideas/Beginner/README.md) — Build the classic guessing game in the browser with a UI. Reinforces DOM manipulation and event listeners.
4. [To-Do List Manager](../Project-Ideas/Beginner/README.md) — A browser-based to-do app with add, complete, and delete functionality. Store tasks in `localStorage` for persistence.
5. [Weather CLI Tool](../Project-Ideas/Beginner/README.md) — Adapt this to a browser app: fetch weather data from the Open-Meteo API and display it on a styled page.

**Resources:**
- [JavaScript Cheatsheet](../Resources/Cheatsheets/JavaScript-Cheatsheet.md) — syntax reference for the language features you're learning
- [JavaScript Snippets](../Resources/Snippets/JavaScript-Snippets.md) — reusable patterns for API requests, DOM manipulation, and more
- [DSA Study Guide](../Resources/Interview-Prep/DSA-Study-Guide.md) — start reading the arrays and strings sections to build CS fundamentals

**Milestone:** You can build a dynamic, interactive web app that fetches data from an external API and updates the DOM without a page reload.

---

## Phase 3: React & Modern Tooling (~6 weeks)

**Goal:** Build component-based UIs with React and understand the modern frontend ecosystem.

**Roadmap:** [Frontend Developer Roadmap](../Roadmaps/Frontend-Developer.md)

**What to learn:**
- React fundamentals (JSX, components, props, state, hooks)
- `useState`, `useEffect`, `useContext`
- React Router for client-side navigation
- Fetching data in React (useEffect + fetch / axios)
- CSS Modules or Tailwind CSS for styling
- Vite or Create React App for project setup
- TypeScript basics (types, interfaces, generics)

**Projects to Build:**

6. [Flashcard Study App](../Project-Ideas/Beginner/README.md) — Rebuild this as a React app with multiple decks, flip animations, and session score tracking.
7. [Habit Tracker Mobile App](../Project-Ideas/Intermediate/README.md) — Build the frontend in React: habit creation, daily check-off, streak display, and a completion heatmap.

**Resources:**
- [React Cheatsheet](../Resources/Cheatsheets/React-Cheatsheet.md) — hooks, component patterns, and common React APIs
- [TypeScript Cheatsheet](../Resources/Cheatsheets/TypeScript-Cheatsheet.md) — type annotations, interfaces, and generics
- [Regex Cheatsheet](../Resources/Cheatsheets/Regex-Cheatsheet.md) — useful for form validation patterns

**Milestone:** You can scaffold a React app from scratch, manage state with hooks, fetch and display data from an API, and navigate between pages with React Router.

---

## Phase 4: Portfolio & Interview Prep (~6 weeks)

**Goal:** Polish your portfolio, practice interview questions, and apply for jobs.

**Roadmap:** [Frontend Developer Roadmap](../Roadmaps/Frontend-Developer.md)

**What to learn:**
- Web performance basics (lazy loading, code splitting, Lighthouse)
- Accessibility fundamentals (semantic HTML, ARIA, keyboard navigation)
- Testing basics (Jest, React Testing Library)
- Deploying to Vercel or Netlify
- Technical interview patterns (arrays, strings, hash maps)

**Projects to Build:**

8. [Personal Finance Dashboard](../Project-Ideas/Intermediate/README.md) — A full React app with charts (recharts or Chart.js), category filtering, and a budget tracker. This is your capstone portfolio piece.

**Resources:**
- [DSA Study Guide](../Resources/Interview-Prep/DSA-Study-Guide.md) — arrays, strings, and hash maps are the most common frontend interview topics
- [Big-O Cheatsheet](../Resources/Interview-Prep/Big-O-Cheatsheet.md) — understand time and space complexity for interview questions
- [Behavioral Interview Guide](../Resources/Interview-Prep/Behavioral-Interview-Guide.md) — prepare STAR-format answers for HR and hiring manager rounds
- [Practice Problems](../Resources/Interview-Prep/Practice-Problems.md) — work through easy and medium problems on arrays and strings
- [GitHub Profile Guide](../Resources/Guides/GitHub-Profile-Guide.md) — make your GitHub profile stand out to recruiters
- [Open Source Guide](../Resources/Guides/Open-Source-Guide.md) — contribute to an open source project to strengthen your portfolio

**Milestone:** You have 3+ deployed projects on your portfolio, a polished GitHub profile, and can solve easy LeetCode problems in JavaScript.
