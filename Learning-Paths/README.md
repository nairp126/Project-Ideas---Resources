## How to Use a Learning Path

1. **Read the Overview** — each path starts with a description of who it's for and the total time commitment.
2. **Follow the phases in order** — each phase builds on the previous one. Don't skip ahead.
3. **Build the projects** — projects are listed in recommended build order. Completing them is more important than rushing through theory.
4. **Use the linked resources** — cheatsheets, guides, and reference material are linked at each phase where they're most relevant.
5. **Check the Roadmap** — each path links to a detailed career roadmap for deeper context on the technologies you're learning.
