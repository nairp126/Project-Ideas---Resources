# Career Changer Path

## Overview

**Who this is for:** Professionals switching into tech from a non-programming background — teachers, marketers, accountants, healthcare workers, lawyers, or anyone who has built a career in another field and now wants to transition into software development, data, or a related tech role.

**Estimated total time:** 10–14 months (assuming 10–15 hours per week alongside existing work)

**Relevant Roadmaps:**
- [Frontend Developer Roadmap](../Roadmaps/Frontend-Developer.md)
- [Backend Engineer Roadmap](../Roadmaps/Backend-Engineer.md)
- [Data Scientist Roadmap](../Roadmaps/Data-Scientist.md)

This path is different from the zero-to-junior paths. It starts with a longer foundational phase because career changers often need to build mental models from scratch while also managing the psychological challenge of being a beginner again. The path then branches into three specialization tracks so you can choose the direction that best fits your background and goals.

---

## Phase 1: Foundations — How Computers and Code Work (~6 weeks)

**Goal:** Build a solid mental model of how software works before writing a single line of production code.

**What to learn:**
- How computers work: CPU, memory, storage, operating system basics
- How the internet works: HTTP, DNS, browsers, servers, IP addresses
- What programming is: source code, compilation vs. interpretation, runtime
- Command line basics: navigating the file system, running scripts, pipes and redirection
- Git fundamentals: init, add, commit, push, pull, branches, merge
- Choosing your first language (recommendation: Python — readable, versatile, in demand)
- Python basics: variables, data types, conditionals, loops, functions

**Projects to Build:**

1. [Simple Calculator](../Project-Ideas/Beginner/README.md) — Your first real program. Focus on understanding the input → process → output loop, not on the complexity of the project.
2. [Number Guessing Game](../Project-Ideas/Beginner/README.md) — Introduces loops, conditionals, and random number generation. Small enough to finish in a weekend, satisfying enough to build confidence.

**Resources:**
- [Linux/Bash Cheatsheet](../Resources/Cheatsheets/Linux-Bash-Cheatsheet.md) — the terminal commands you'll use every single day
- [Git Cheatsheet](../Resources/Cheatsheets/Git-Cheatsheet.md) — version control is non-negotiable; learn it early
- [Python Cheatsheet](../Resources/Cheatsheets/Python-Cheatsheet.md) — keep this open while you're learning Python syntax
- [Developer Workflow Guide](../Resources/Guides/Developer-Workflow-Guide.md) — set up your development environment properly from day one

**Career Changer Tip:** Your previous career is an asset, not a liability. A teacher who codes thinks about user experience differently. An accountant who codes understands data integrity intuitively. A marketer who codes builds products people actually want. Keep this in mind as you choose your specialization.

**Milestone:** You can write a Python script from scratch, run it from the terminal, and push it to GitHub.

## Phase 2: Core Programming Concepts (~6 weeks)

**Goal:** Solidify programming fundamentals and write programs that solve real problems.

**What to learn:**
- Functions: parameters, return values, scope, recursion basics
- Data structures: lists, dictionaries, sets — when to use each
- Object-oriented programming: classes, objects, methods, inheritance
- File I/O: reading and writing text files, CSV, JSON
- Error handling: try/except, writing defensive code
- Modules and packages: importing, using third-party libraries (pip)
- Basic algorithms: searching, sorting, understanding Big-O at a high level

**Projects to Build:**

3. [To-Do List Manager](../Project-Ideas/Beginner/README.md) — Implement full CRUD with file persistence. This is the "Hello World" of real applications.
4. [Password Strength Checker](../Project-Ideas/Beginner/README.md) — Reinforces string manipulation, boolean logic, and writing reusable functions.
5. [Flashcard Study App](../Project-Ideas/Beginner/README.md) — Object-oriented design practice: Card and Deck classes, session tracking, and file-based persistence.

**Resources:**
- [Python Snippets](../Resources/Snippets/Python-Snippets.md) — reusable patterns for authentication, file I/O, string manipulation, and data processing
- [Sorting Algorithms](../Resources/Algorithms/Sorting-Algorithms.md) — understand what's happening under the hood when you call `.sort()`
- [Data Structures Reference](../Resources/Algorithms/Data-Structures-Reference.md) — arrays, hash maps, and linked lists explained with code examples

**Career Changer Tip:** At this stage, imposter syndrome is at its peak. Everyone feels this way. The antidote is shipping projects — even small ones. Each project you finish is proof that you can do this.

**Milestone:** You can design a multi-class Python program, handle errors gracefully, and explain your code to someone else.

## Phase 3: Choose Your Specialization Track (~2 weeks)

**Goal:** Decide which direction to specialize in based on your background, interests, and the job market in your area.

Use this phase to research, not to code. Talk to people in each field, read job descriptions, and reflect on what excites you.

### Track A: Frontend / Web Development
**Best for:** Designers, marketers, teachers, anyone who cares about how things look and feel.
**Continue with:** [Zero to Junior Frontend Developer](./Zero-to-Junior-Frontend.md) — start at Phase 2 (JavaScript Fundamentals).

### Track B: Backend / API Development
**Best for:** Accountants, analysts, engineers from other disciplines, anyone who cares about how systems work under the hood.
**Continue with:** [Zero to Junior Backend Developer](./Zero-to-Junior-Backend.md) — start at Phase 2 (Databases & SQL).

### Track C: Data Science / Analytics
**Best for:** Researchers, analysts, scientists, healthcare workers, anyone who already works with data and wants to go deeper.
**Continue with:** [Zero to Data Scientist](./Zero-to-Data-Scientist.md) — start at Phase 2 (Data Manipulation & Visualization).

**Resources for deciding:**
- [Frontend Developer Roadmap](../Roadmaps/Frontend-Developer.md) — see what a frontend career looks like
- [Backend Engineer Roadmap](../Roadmaps/Backend-Engineer.md) — see what a backend career looks like
- [Data Scientist Roadmap](../Roadmaps/Data-Scientist.md) — see what a data science career looks like

## Phase 5: Job Search & Interview Prep (~6 weeks)

**Goal:** Translate your new skills and your previous career experience into a compelling job application.

**What to learn:**
- How to write a tech resume that highlights transferable skills
- How to talk about your career change in interviews (your story matters)
- Technical interview preparation for your chosen track
- Networking in the tech community (meetups, Twitter/X, LinkedIn, Discord)
- How to evaluate job offers (compensation, growth, culture, tech stack)

**Projects to Build:**

8. Pick one project from the [Intermediate Project Ideas](../Project-Ideas/Intermediate/README.md) that connects to your previous career. A teacher might build a quiz platform. An accountant might build a personal finance dashboard. A healthcare worker might build a symptom tracker. This project tells your story.

**Resources:**
- [DSA Study Guide](../Resources/Interview-Prep/DSA-Study-Guide.md) — arrays, hash maps, and strings are the most common topics across all tracks
- [Behavioral Interview Guide](../Resources/Interview-Prep/Behavioral-Interview-Guide.md) — your previous career gives you rich STAR stories; learn how to tell them in a tech context
- [Big-O Cheatsheet](../Resources/Interview-Prep/Big-O-Cheatsheet.md) — understand complexity well enough to discuss it in interviews
- [Practice Problems](../Project-Ideas/../Resources/Interview-Prep/Practice-Problems.md) — focus on easy problems first; consistency beats cramming
- [Open Source Guide](../Resources/Guides/Open-Source-Guide.md) — contributing to open source is one of the best ways to get noticed and build real-world experience
- [GitHub Profile Guide](../Resources/Guides/GitHub-Profile-Guide.md) — your GitHub profile is your portfolio; make it count

**Career Changer Tip:** Your non-tech background is a differentiator. Companies want engineers who understand the domain they're building for. A former nurse building healthcare software, a former teacher building edtech, or a former accountant building fintech brings context that a fresh CS graduate doesn't have. Lead with this in your cover letters and interviews.

**Milestone:** You have a polished resume, a strong GitHub profile, 3+ deployed projects, and have submitted at least 20 job applications.
